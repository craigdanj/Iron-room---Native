# Iron Room Soniclaw 0.1.0

First standalone application built on Soniclaw 0.144.0. Reuses the existing 201 acoustic recordings, 17 articulations, 11 channels and 2,375 grooves. Adds native pads, groove search, drum editing, patterns/song clips, channel processing, MIDI performance/overdub, portable project state, custom recordings and offline WAV/MIDI delivery.

Workflow, public modules, lifecycle, persistence, bounds, failures and known limits are documented in [README](../../README.md) and [architecture](../ARCHITECTURE.md). Run the binary without flags for the UI or use `--help` for headless commands. Validation evidence is recorded separately in [VALIDATION.md](../VALIDATION.md); unexecuted targets are not described as passed.

The `.ironroom-s` schema is new and distinct from the previous JUCE `.ironroom` and browser JSON. No migration or plug-in compatibility is claimed. The old projects, original sample files and original application remain untouched.
